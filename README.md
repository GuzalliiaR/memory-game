# Memory Game

Memory Game - игра на поиск пар карточек за минимальное количество ходов.

🔗 **Демо:** https://guzalliiar.github.io/memory-game/

## Описание

На игровом поле 16 карточек - 8 пар с одинаковым изображением. Игра стартует при запуске страницы: карточки перемешаны и лежат лицевой стороной вниз, счетчики обнулены.

Правила:

- открытие двух карточек = один ход;
- две открытые карточки совпали = +1 пар (пара остается открытой);
- две открытые карточки не совпали = +0 пар (открытые карточки видны 1 сек., затем закрываются);
- после открытия всех 8 пар, открывается модальное окно "Победа";
- результат каждой победы сохраняется в `localStorage`, в таблице лидеров показываются 10 лучших игр.

## Возможности

- автоматический старт и перемешивание карточек (алгоритм Фишера — Йетса);
- кнопка «Новая игра» — перезапуск без перезагрузки страницы, в том числе с открытой несовпавшей парой (её таймер отменяется);
- кнопка «Таблица лидеров» — топ-10 результатов с местом, числом ходов и датой в формате ДД.ММ.ГГГГ;
- модальные окна на `<dialog>` с блокировкой прокрутки, закрытием по кнопке, клику по фону и клавише Escape;
- плавные анимации открытия и закрытия модальных окон;
- вся разметка генерируется через `document.createElement`.

## Стек

- HTML, CSS, JavaScript (ES-модули);
- без сторонних библиотек и фреймворков;
- `localStorage` для хранения результатов.

## Локальный запуск

Проект использует ES-модули (`<script type="module">`), поэтому открывать [`index.html`](index.html) напрямую через `file://` нельзя — браузер заблокирует импорты.

### Запуск с расширением Live Server (VS Code)

1. Склонируйте репозиторий и переключитесь на рабочую ветку:
   ```bash
   git clone https://github.com/GuzalliiaR/memory-game.git
   cd memory-game
   git checkout memory-game
   ```
2. Откройте папку проекта в VS Code.
3. Установите расширение **Live Server**.
4. Нажмите правой кнопкой на [`index.html`](index.html) → **Open with Live Server**.
5. Приложение откроется по адресу вида `http://127.0.0.1:5500/index.html`.
